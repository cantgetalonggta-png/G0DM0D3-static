# G0DM0D3 static deploy (keyless)

- Source: https://github.com/elder-plinius/G0DM0D3 (AGPL-3.0)
- Hosted mirror: no API keys in source or env
- After open: Settings → API Keys → paste OpenRouter/Venice key (browser localStorage only)
- Or: Log in with OpenRouter OAuth on the UI

Do NOT commit secrets. Rotate any key that was ever pasted into chat.
